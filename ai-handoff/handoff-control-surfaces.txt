TUI DASHBOARD — scripts/tui.js (1379 lines) — WHAT EXISTS
═══════════════════════════════════════════════════════════════

This is a zero-dependency Node.js terminal dashboard using raw ANSI.
Terminal set to raw mode, refreshes every 2 seconds.

Display sections (shown in screenshot):
  • Title bar: Mode ([LIVE]/[SETUP]), [REAPER], ONLINE, ● RUNNING
  • Now Playing (left): song, artist, key, bar/BPM, position/duration,
    playing state (● HUD PLAYING local)
  • Queue (right): Tab-toggle Singers view or Setlist view
    - Singers: list of queued singers, wait time estimates
    - Setlist: band song queue with current/next/prev highlighting
  • Stats bar: Singers #, Setlist size, Round counter, ETA,
    Karaoke ON/OFF, ONLINE/OFFLINE, Dell status, current song
  • URLs: iPhone, Stage HUD, Singer Queue, Band View IPs
  • Actions bar: full keyboard shortcut reference
  • Log panel: last ~150 timestamped events

Keyboard controls (selected):
  ← →   Switch panel focus (Now Playing / Queue)
  Tab   Toggle Singers / Setlist in Queue panel
  ↑ ↓   Navigate items
  a     Search + add song
  p     Promote singer to main queue
  B     Kick/ban singer (confirm)
  x     Remove item (confirm for singers)
  c     Clear round (confirm)
  n/b   Load next / previous song
  Space Play / Stop / Start setlist
  Enter "Play now" — promote to main queue
  Shift+K Toggle karaoke ON/OFF
  Shift+L Go LIVE (system optimize, activate Dell HUD)
  m     Toggle bumper music
  [ ]   Bumper volume -/+5%
  E     Export setlist
  I     Import setlist
  ?     Settings (max songs, bumper vol, karaoke toggle)
  w     WiFi info overlay
  o     Toggle online/offline external sync
  q     Quit (stops bumper, stops server, restores AWDL)

Overlay modes: search picker, confirm dialog, WiFi info,
setlist picker, settings, export name input.

The TUI was built ~a month ago across 11 sessions (see BUILD_LOG.md).
